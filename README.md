# 우리 반 어드벤트 캘린더

서랍을 열면 우리 반 학생 한 명이 무작위로 뽑히는 크리스마스 어드벤트 캘린더 웹앱입니다.
로그인 없이 링크로 접속하고, 명단과 기록은 각자의 브라우저에 저장됩니다.

## 선생님용 사용법

1. **명단** 탭에서 학생 이름을 한 줄에 한 명씩 붙여넣고 `명단에 추가`를 누릅니다.
   처음에 보이는 1번~20번은 예시이며, 이름을 추가하면 자동으로 사라집니다.
2. **캘린더** 탭에서 서랍을 누르면 학생이 뽑히고 결과 카드(일러스트 + 이름)가 나옵니다.
   - 서랍 수 = 학생 수 (20명이면 20칸)
   - 한 번 뽑힌 학생은 다시 뽑히지 않습니다.
   - 결석 등으로 다시 뽑아야 하면 결과 카드의 `다시 뽑기`를 누르세요.
   - 오른쪽 위 ♪ 버튼으로 배경 음악(고요한 밤 오르골 편곡, 반복 재생), ⛶ 버튼으로 전체화면(교실 TV용)
   - 배경 음악은 뽑기 연출 동안 자동으로 작아졌다가 돌아옵니다.
3. **기록** 탭: 뽑힌 순서 확인, 서랍 다시 닫기(취소), 엑셀(CSV) 저장, 표 복사, 인쇄
4. **설정** 탭: 시작 날짜, 날짜 잠금(그날이 되어야 열림), 주말 건너뛰기, 효과음, 눈, 반 추가/삭제, 백업

> 명단과 기록은 **이 브라우저에만** 저장됩니다. 브라우저 기록을 지우면 사라지니,
> 다른 컴퓨터로 옮기거나 보관할 때는 설정 → `백업 파일 저장`을 이용하세요.

## 배포 (GitHub Pages, 무료)

1. GitHub에 새 저장소를 만듭니다 (예: `advent-calendar`, Public).
2. 이 폴더의 파일을 모두 올립니다: `index.html`, `style.css`, `storage.js`, `app.js`, `assets/`
3. 저장소의 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://<아이디>.github.io/advent-calendar/` 링크가 생깁니다. 이 링크를 선생님들께 공유하세요.

Netlify를 쓰려면 app.netlify.com/drop 에 이 폴더를 끌어다 놓기만 하면 됩니다.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 뽑기·명단·기록·설정 동작 |
| `storage.js` | 저장(localStorage) — 클라우드 저장으로 바꿀 때 이 파일만 수정 |
| `assets/` | 이미지(WebP) + 배경 음악 `bgm-silent-night.mp3`, 전체 약 2.7MB |

이미지를 바꾸려면 같은 파일 이름으로 `assets/`에 넣으면 됩니다.
일러스트는 서랍 번호에 맞춰 `illust-01`~`illust-24`가 쓰이고, 25번 서랍부터는 1번부터 다시 쓰입니다.
